# ViP Yemen v1.0.7-web

هذا الإصدار يضم آخر مصدر الويب والتوثيق المحدث لميزات العربية والإنجليزية، التاريخ الميلادي والهجري، خلفية خريطة اليمن الزجاجية، أدوات تكبير النصوص والصور، دعوة القنوات الاجتماعية، الإعلان الابتدائي ثنائي اللغة، وإصلاحات منع تراكب صورة المطور.

## التحقق

اجتاز المصدر TypeScript و18 اختبار Vitest وبناء الإنتاج، كما اجتاز smoke test للمسارين `/` و`/admin` والمعاينة البصرية عند 1280×720 و390×844، مع اختبار الوضع الإنجليزي عبر `?lang=en`.

## ملاحظة مهمة عن تطبيقات الهاتف

هذا إصدار مصدر ويب موثق، ولا يحتوي APK أو AAB جديدين مرفقين؛ لا يجوز استخدام ملفات الإصدار السابق ووصفها بأنها مبنية من هذا المصدر. إنشاء APK/AAB النهائي يتطلب تشغيل Android SDK أو Codemagic، وإنشاء iOS يتطلب macOS/Xcode وبيانات توقيع Apple. بعد منح صلاحية GitHub Actions `workflows` يمكن تشغيل فحص CI تلقائيًا.
