## 1) نبذة عن المنصة

**ViP Yemen** منصة يمنية شاملة متعددة المهام تخدم السوق اليمني في أربعة مسارات رئيسية:

1. **التوظيف والفرص** — ربط الباحثين عن عمل بالمنشآت والجهات الطالبة للكفاءات.
2. **التسويق العقاري** — عرض وطلب العقارات (أراضٍ، منازل، عمارات، فلل) مع تواصل مباشر.
3. **التسويق الإلكتروني** — عرض وطلب المنتجات والسلع والأجهزة والسيارات مع إمكانية رفع الصور والفيديوهات القصيرة.
4. **البرمجيات وتطوير التطبيقات** — طلب بناء تطبيقات الهواتف والمنصات والأنظمة.

إضافة إلى **العروض الترويجية والإعلانات** التي تُدار بالكامل من لوحة التحكم وتظهر آليًا في شريط الإعلانات وواجهة المنصة.

**آلية العمل الأساسية (نموذج المراجعة الآمنة):**
- يقدّم المستخدم طلبه (بيانات + مرفقات: صور/فيديوهات/PDF) عبر بوابة الطلبات.
- يصل الطلب **أولًا وبشكل خاص وسري** إلى لوحة التحكم في القسم المخصص له.
- تقوم الإدارة بالتدقيق والمراجعة والتعديل، ثم تنشر الطلب **بضغطة زر**.
- يُعرض الطلب المنشور تلقائيًا في قسمه المخصص على واجهة المنصة، مع إمكانية التزامن مع قنوات المنصة الرقمية.

## 2) المكونات التقنية

| الطبقة | التقنية |
|---|---|
| الواجهة الأمامية (ويب / PWA) | React + TypeScript + Vite + Wouter |
| الخادم (Backend) | Node.js + tRPC (REST عبر `/api/trpc`) + Zod |
| قاعدة البيانات الحالية | SQLite (Drizzle ORM) — مع مخطط Supabase كامل جاهز للنشر |
| قاعدة بيانات سحابية (الانتقال) | **Supabase** (PostgreSQL + Storage + Auth) — الملفات في `supabase/` |
| تطبيق أندرويد | **Capacitor** (تطبيق أصلي حقيقي بملف APK و AAB) |
| تطبيق iOS | مشروع Capacitor iOS جاهز (`capacitor-app/ios`) |
| التصميم | CSS مخصص + خط IBM Plex Sans Arabic + أيقونات Lucide |
| التحقق من الأرقام | التحقق من الأرقام اليمنية (Yemeni phone validation) |
| الأمان | تشفير SHA-256 محلي، حماية معدلات المحاولات، سجل تدقيقي، بصمة الدخول |

## 3) الأقسام والخدمات

### أ) قسم التوظيف
- الباحث عن عمل: الاسم، الهاتف، العنوان، المؤهلات، السيرة الذاتية، المرفقات.
- جهة التوظيف: اسم المنشأة، المهنة المطلوبة، الشروط، نطاق الراتب.

### ب) قسم التسويق العقاري
- مالك العقار: تفاصيل العقار (أرض/منزل/عمارة/فيلا) + صور + موقع على الخريطة.
- العميل الطالب: مواصفات العقار المطلوب.
- ربط تلقائي برقم واتساب أعمال المنصة **00967711780999**.

### ج) قسم التسويق الإلكتروني
- التاجر/البائع: نوع المنتج ومواصفاته + صور + فيديو قصير + السعر.
- العميل الطالب: تفاصيل الطلب المطلوب.
- أي منتج يُباع يُعلَّم تلقائيًا بشارة **«تم البيع»**.

### د) قسم البرمجيات وتطوير التطبيقات
- طلبات بناء التطبيقات والمنصات والأنظمة ولوحات التحكم.
- يصل الطلب إلى الإدارة للمراجعة والتواصل المباشر.

### هـ) العروض الترويجية والإعلانات
- إنشاء وتحرير ونشر الإعلانات من لوحة التحكم (شريط إعلاني أعلى المنصة يتحرك ببطء).
- تحديد الأولوية وتواريخ البدء والانتهاء، والنشر الفوري من داخل اللوحة.

## 4) لوحة التحكم (مؤمنة بالكامل)

- **الدخول:** البريد الإلكتروني `vipservicesyemen@gmail.com` مع كلمة مرور افتراضية تُغيَّر عند أول دخول **بشكل حقيقي وفعلي** (التغيير محفوظ ومشفر).
- **إعادة التعيين:** عبر رمز استعادة آمن يُرسل إلى بريد الإدارة.
- **بصمة/وجه:** دعم تسجيل الدخول بالبصمة عند توفر الجهاز.
- **الأقسام:** نظرة عامة · التوظيف · العقارات · التسويق · البرمجيات · الإعلانات · العروض · المحاسبة · العقود · الأرشيف · الأتمتة · الإعدادات.
- **المراجعة والنشر:** قبول/رفض/أرشفة أي طلب وضبط حالته (قيد المراجعة، موافقة، رفض، أرشفة، تم البيع).
- **أدوات المطور/المالك:** إدارة الأصول البصرية والثيمات والأقسام الإضافية مع سجل إصدارات واسترجاع.
- **الإعدادات:** روابط المتجر (Google Play / App Store / تحميل مباشر) — تُفعّل زر «تحميل التطبيق» آليًا دون أي توجيه لروابط التطوير.

**الحماية:** صفحات اللوحة والدخول محجوبة من الفهرسة (`noindex`)، أي مسار إداري غير معروف يُوجّه تلقائيًا لصفحة الدخول (لا تظهر «الصفحة غير موجودة» أبدًا)، مع قفل الحساب بعد المحاولات المتكررة.

## 6) التحديثات التلقائية والإشعارات

- فحص دوري لإصدارات جديدة (عبر GitHub API) بشكل هادئ خلف الكواليس.

## 7) الأمان والخصوصية

- حماية المسارات ورؤوس أمان صارمة (CSP، X-Frame-Options، nosniff، HSTS، Referrer-Policy).
- بيانات لوحة التحكم غير مفهرسة ومخفية عن محركات البحث.
- رفع الملفات مقيد بالأنواع والأحجام (صور/PDF حتى 8MB، فيديو قصير حتى 25MB، حتى 6 ملفات).
- التحقق من صحة الأرقام اليمنية قبل قبول الطلبات.
- سجل أمني تدقيقي (تسجيل الدخول، الفشل، تغيير كلمات المرور، البصمة).
- لا تُنشر أي بيانات مستخدم إلا بعد موافقة الإدارة.

## 9) ملفات الباك اند وقاعدة البيانات

مجلد **`supabase/`** يحتوي على المخطط الكامل والجاهز للنشر:
- `migrations/001_initial_schema.sql` — الجداول: users, submissions, submission_attachments, advertisements, offers, offer_attachments, site_assets, site_themes, site_sections, site_content_revisions, contacts, notifications, activity_log, settings.
- `migrations/002_storage_buckets.sql` — دلائل التخزين للمرفقات والأصول.
- `seed/001_initial_data.sql` — البيانات الأولية.
- `types.ts` — أنواع TypeScript الكاملة.
- `config.toml` + `package.json` — إعدادات مشروع Supabase المحلي.

خطوات النشر على Supabase موثقة في `supabase/README.md`.
